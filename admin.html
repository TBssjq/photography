如何上线到 GitHub Pages

  1. 在本后台改好内容，点 保存。
  2. 点 导出 ZIP 下载 suibei-photography.zip。
  3. 解压后把 dist/ 内容推送到 GitHub 仓库的 main 分支。
  4. 仓库 Settings → Pages → Source 选 GitHub Actions 或 main / root。

也可直接双击项目根目录的 deploy.ps1 一键发布（需已安装 Git 与 Go）。
